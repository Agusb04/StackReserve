# Entregas

Esta carpeta no guarda snapshots completos del proyecto. Aquí sólo viven los manifiestos por ejercicio:

- `entregas/ejercicio-01.md`
- `entregas/ejercicio-02.md`
- `entregas/ejercicio-03.md`
- `entregas/ejercicio-04.md`

Cada manifiesto debe resumir:

- objetivo de la entrega;
- artefactos trabajados;
- cambios principales;
- feedback incorporado;
- pendientes.

Los artefactos vivos del proyecto viven en `docs/`, `src/` y `db/`.
