La demo verifica una API de ejemplo no perteneciente al dominio en el mismo localhost.
Para agregar tu propio servicio: 1. Creá el endpoint en Spring Boot. 2. Copiá esta story y dejá los mismos archivos comunes: `storybook-demo.config.json` y `storybook-demo.js`. 3. Cambiá solo `storybook-demo.config.json`: `apiUrl`, `requestLabel`, `title`, `subtitle`, `successHint` y `failureHint`. 4. No escribas JavaScript nuevo por historia: `storybook-demo.js` ya lee la config, hace el `fetch` y pinta la respuesta.
Si esto no responde, levantá la app con Spring Boot y reintentá la carga.
